# 派为资讯发布（astrbot_plugin_publish_bridge）

在 QQ 群内发送指令，通过 AstrBot 机器人把内容发布到指定平台的 HTTP 发布接口。

## 功能

- **模板发布**：一次配置「平台 + action + 分类 + 固定字段」，指令里只写模板名
- **平台发布**：兼容旧格式，直接指定平台
- **发布预览**：只渲染请求体，不真正发送，方便联调
- **动态字段**：`price=9.9`、`amount=10`、`unit=件` 等按条传入
- **中文参数别名**：`价格=9.9`、`数量=10` 自动映射
- **纯链接抓取**：正文是单个链接时，自动抓取文章正文再发布
- **WebUI 发布面板**：在插件详情页查看平台/模板、预览和快捷发布
- 多平台配置、WebUI 可视化增删
- 鉴权：`Bearer Token` / 自定义 Header / `MD5 签名` / 无鉴权
- 仅群聊、仅管理员可用的开关
- 异步 HTTP（aiohttp），超时与错误友好提示
- 自动识别平台业务码（HTTP 200 但 `code != 0` 也会报失败）
- 成功回复带平台状态（如「待审核」）和文章链接

## 安装

1. 将本目录放到 AstrBot 的插件目录：

   ```
   AstrBot/data/plugins/astrbot_plugin_publish_bridge/
   ```

2. 重启 AstrBot，或在 WebUI → 插件 页面点击刷新 / 重载。
3. 打开「插件 → 派为资讯发布 → 配置」，添加平台即可；资讯/产品/需求模板已内置。
4. 在 QQ 群发送 `/发布列表` 查看模板和平台，发送 `/发布帮助` 查看用法和示例。

## WebUI 发布面板

插件安装并启用后，在 WebUI → 插件 → 派为资讯发布 → 详情页，会多出一个 **「发布面板」** 下级菜单。

面板包含：

- **概览**：平台数、模板数、默认平台
- **发布模板**：模板名、平台、action、分类 ID、必填字段
- **发布平台**：API 地址、HTTP 方法、鉴权方式
- **快捷发布**：选择模板/平台，填写标题、正文和动态参数，支持「预览请求」和「发布」

正文填写单个链接时，同样会自动抓取文章正文。

> 发布面板依赖 AstrBot 的插件视图 API（`register_web_api` + `views/`）。如果安装后没有看到该菜单，说明当前 AstrBot 版本较旧，插件本体仍可正常使用 QQ 指令。

## 指令设计

### 1. 模板发布（推荐）

```
/发布 <模板> <标题> | <正文>
/发布 <模板> <标题> | <正文> | key=value, key=value
```

示例：

```
/发布 资讯 今日观察 | 今天学习了 AstrBot 插件开发。
/发布 产品 新款工具 | 高效稳定的工具。 | price=9.9, amount=10, unit=件
/发布 需求 寻求合作 | 需要一位前端开发者。 | days=7
```

标题和正文也可以用换行分隔：

```
/发布 资讯 今日观察
第一段正文……
第二段正文……
```

### 2. 平台发布（兼容旧格式）

```
/发布 <平台> <标题> | <正文>
```

示例：

```
/发布 321788 AstrBot 接口联调测试 | 这是一条测试内容，可删除。
```

平台模式使用平台配置里的 `extra_body`，不会读取模板。

### 3. 发布预览（不发送）

```
/发布预览 <模板或平台> <标题> | <正文> [| key=value]
```

示例：

```
/发布预览 产品 新款工具 | 高效稳定的工具。 | price=9.9, amount=10
```

返回渲染后的请求 JSON（`sign` 打码），用于确认字段是否符合平台要求。

### 4. 查看帮助 / 模板 / 平台

```
/发布帮助   # 显示完整用法和使用示例
/发布列表   # 列出已配置的模板和平台
```

`/发布帮助` 会按已配置模板动态生成使用示例，实际输出类似：

```
📮 发布帮助

【使用示例】
资讯｜发布一条资讯：
  /发布 资讯 今日观察 | 今天学习了 AstrBot 插件开发。

产品｜发布产品信息（需价格）：
  /发布 产品 新款工具 | 高效稳定。 | price=9.9, amount=10, unit=件

需求｜发布需求信息：
  /发布 需求 寻求合作 | 需要一位前端开发者。 | days=7

预览（不发送）：
  /发布预览 资讯 今日观察 | 今天学习了 AstrBot 插件开发。

查看模板和平台：
  /发布列表

说明：标题和正文用 | 或 ｜ 分隔；也可以第一行写标题、后续行写正文。
```

> 模板的 `description` 会显示在模板名后面；增删模板后重载插件即可更新帮助内容。

### 解析优先级

1. 首个词匹配**模板名** → 模板发布
2. 首个词匹配**平台名** → 平台发布
3. 都不匹配 → 若有默认平台，整段内容走默认平台
4. 仍不匹配 → 提示未找到

> 模板名优先于平台名；建议模板名用「资讯 / 产品 / 需求」这类语义化短词。

## 纯链接自动抓取正文

当正文是**单个 http(s) 链接**（前后没有其他文字）时，插件会先抓取该页面、提取文章正文，再发布：

```
/发布 资讯 今日观察 | https://m.eeo.com.cn/2024/0329/648490.shtml
```

- 自动识别纯链接，普通文字内容不受影响
- 使用浏览器 UA 抓取，自动识别 UTF-8 / GB18030 编码
- 优先提取 `<p>` 和标题文本，过滤脚本、导航、时间戳等杂项
- 抓取到的正文会转义并包成 `<p>` 段落
- 抓取失败会明确提示，**不会**把链接本身当正文发布

相关配置：

| 配置项 | 默认 | 说明 |
|---|---|---|
| 纯链接自动抓取正文 | 开启 | 关闭后直接发布链接 |
| 链接抓取超时（秒） | 20 | 范围 5–60 |
| 抓取正文最大字数 | 20000 | 范围 1000–100000，超出截断 |

> 如果目标站点有反爬或需要登录，抓取可能失败；此时可关闭自动抓取，或改为手动粘贴正文。

## 内置发布模板

模板已固定内置，**不需要在 WebUI 配置**。平台名称自动使用「默认发布平台」；未配置默认平台时使用平台列表中的第一个平台。

| 模板 | action | 分类 ID | 固定字段 | 必填 |
|---|---|---|---|---|
| `资讯` | `article` | `44730`（最新资讯） | 无 | 标题、正文 |
| `产品` | `product` | `44632`（功能软件） | `unit=件` | 标题、正文、price |
| `需求` | `demand` | `44508`（功能软件） | 无 | 标题、正文 |

示例：

```
/发布 资讯 今日观察 | 今天学习了 AstrBot 插件开发。
/发布 产品 新款工具 | 高效稳定。 | price=9.9, amount=10, unit=套
/发布 需求 寻求合作 | 需要一位前端开发者。 | days=7
```

> 分类 ID 来自 321788.cn 实测。如果换平台或分类调整，需要修改 `main.py` 里的 `BUILTIN_TEMPLATES` 常量。

### 动态字段

模板发布时，第三段 `|` 之后可以写 `key=value`：

```
/发布 产品 新款工具 | 高效稳定。 | price=9.9, amount=10, unit=件
```

- 多个字段用 `,`、`，`、`;`、`；` 分隔
- 值会自动转成数字/布尔值（`9.9` → float，`10` → int，`true` → bool）
- 键支持中文别名：

| 中文别名 | 字段 |
|---|---|
| 价格 / 单价 | `price` |
| 数量 / 库存 | `amount` |
| 单位 | `unit` |
| 品牌 | `brand` |
| 公司 / 企业 | `company` |
| 联系人 / 姓名 | `truename` |
| 手机 / 电话 | `mobile` |
| 标签 | `tag` |
| 天数 / 有效期 | `days` |
| 分类 | `catid` |
| 地址 | `address` |
| 邮箱 | `email` |

- 也支持 `data.xxx=value` 形式（会自动去掉 `data.` 前缀）

### 必填校验

- 标题至少 3 个字符
- 正文不能为空
- `catid` 必须存在（模板或参数中提供）
- `product` 额外要求 `price ≥ 0.1`
- `required_fields` 可追加自定义必填字段

## 平台配置

| 配置项 | 说明 |
|---|---|
| 启用插件 | 关闭后指令不响应 |
| 仅允许在群聊使用 | 默认开启 |
| 仅管理员可用 | 默认开启，建议保持 |
| 管理员白名单 | 填 QQ 号（多个用逗号分隔），用于协议端未回传管理员身份的情况 |
| 默认发布平台 | 指令未指定模板/平台时使用 |
| 在回复中显示平台响应 | 调试用，最多显示 300 字 |
| 纯链接自动抓取正文 | 正文为单个链接时抓取文章正文 |
| 链接抓取超时（秒） | 5–60，默认 20 |
| 抓取正文最大字数 | 1000–100000，默认 20000 |
| 发布平台列表 | 每个平台一条配置 |

每个平台的配置：

| 字段 | 说明 |
|---|---|
| 平台名称 | 指令中使用的标识，如 `321788` |
| 发布 API 地址 | 完整 URL，仅支持 http/https |
| HTTP 方法 | POST / PUT / PATCH |
| 鉴权方式 | bearer / header / md5_sign / none |
| AppID / 应用 ID | md5_sign 模式使用 |
| Token / API Key / Secret | bearer/header 填令牌；md5_sign 填 appsecret |
| 鉴权请求头名称 | `auth_type=header` 时使用，如 `X-API-Key` |
| 正文参数名 | 正文写入请求体的字段，支持 `a.b.c` 嵌套 |
| 标题参数名 | 留空表示不需要标题；模板模式下由模板覆盖 |
| 正文转换为 HTML | 纯文本按行包成 `<p>` |
| 额外请求头 | JSON 对象字符串 |
| 额外请求体字段 | JSON 对象字符串 |
| 请求超时（秒） | 1–120 |
| 校验 HTTPS 证书 | 内网自签名证书时可关闭 |

## 321788.cn 平台对接（已实测）

平台文档：`https://www.321788.cn/api/v1/document.html`

```http
POST https://www.321788.cn/api/v1/index.php
Content-Type: application/json

{
  "appid": "appXXXX",
  "timestamp": 1700000000,
  "sign": "md5(appid + timestamp + appsecret)",
  "action": "article",
  "data": {
    "catid": 44730,
    "title": "标题",
    "content": "<p>正文</p>"
  }
}
```

平台配置：

| 配置项 | 值 |
|---|---|
| 平台名称 | `321788` |
| 发布 API 地址 | `https://www.321788.cn/api/v1/index.php` |
| HTTP 方法 | `POST` |
| 鉴权方式 | `md5_sign` |
| AppID | 平台分配的应用 ID |
| Token / Secret | 平台分配的 appsecret |
| 正文参数名 | `data.content` |
| 标题参数名 | `data.title` |
| 正文转换为 HTML | `true` |
| 请求超时 | `20` |

> ⚠️ 鉴权方式必须选 `md5_sign`（不是 bearer/none），否则请求体不会带 `appid/timestamp/sign`，平台会返回 400「缺少参数 appid」。

实测结果：

| 模块 | action | 分类 ID | 返回 module | 示例 itemid |
|---|---|---|---|---|
| 资讯 | `article` | `44730` | `article` | 930 |
| 产品 | `product` | `44632` | `mall` | 42 |
| 需求 | `demand` | `44508` | `buy` | 324 |

> 平台返回 `status=2` 表示待审核，审核通过后公开链接才可访问。

## 安全建议

- 保持「仅管理员可用」开启，避免群成员向外部平台滥发内容。
- 使用平台提供的**最小权限**令牌，不要把管理员级 Token 填进来。
- 配置文件中的 Token 仅在界面掩码显示，**并未加密存储**，请注意服务器文件权限。
- 本插件不会把 Token 写进日志；日志只记录目标平台、方法、URL 与标题。
- `发布预览` 不会发送请求，可放心用于排查字段问题。

## 常见问题

| 现象 | 排查 |
|---|---|
| 提示「未找到模板或平台」 | 检查模板名称、平台名称拼写；用 `/发布列表` 查看 |
| 提示「缺少必填字段 price」 | 产品发布需要 `| price=9.9` |
| 提示「标题至少 3 个字符」 | 用「标题 \| 正文」格式，标题写完整 |
| 401 / 403 | 检查 Token、鉴权方式、AppID/Secret 是否正确 |
| 404 | 检查 API 地址是否完整（协议、路径、尾部斜杠） |
| 超时 | 平台响应慢或网络不通；可调大超时或关闭 SSL 校验 |
| 400 且提示字段缺失 | 用 `/发布预览` 对照平台文档检查请求体 |
| 400「缺少参数 appid」 | 把该平台「鉴权方式」改为 `md5_sign`，并填写 AppID/Secret |
| 提示「链接正文抓取失败」 | 检查链接可访问性与反爬；可关闭「纯链接自动抓取正文」或调大超时 |
| 抓到的正文不完整 | 页面可能不是 `<p>` 结构或有反爬；可关闭自动抓取、手动粘贴正文 |
| 提示「该指令仅管理员可用」 | 在插件配置的「管理员白名单」填入你的 QQ 号，或关闭「仅管理员可用」 |
| 指令无响应 | 检查是否在群聊、是否有管理员权限、插件是否启用 |

## 后续可扩展

- 同一条内容同时发布到多个模板/平台
- 图片上传（平台有 `upload` 接口，可配合 `thumb` 字段）
- 发布记录持久化与失败重试
- 模板占位符（如 `{date}`、`{user}`、`{group}`）
- 从平台响应中提取链接并写入群公告/数据库

如平台的发布 API 有特殊要求（签名、时间戳、文件上传、OAuth 刷新等），可在 `main.py` 的 `_prepare_request()` 中按需扩展。
